I work on AI products. Lately that means agents that can shop for someone or answer a customer's support question, and tools that show how ChatGPT, Gemini and Google's AI Overviews talk about a brand.

Most of the work is what happens after the demo: making an LLM feature reliable, fast and cheap enough that real people can use it every day.

#### Things I've built

- **[Support Agent](https://github.com/NikhilPatil15/Support-agent)**: a shopping and support assistant for a single brand. It finds products in a Shopify catalog, checks on orders and lives on the site as a chat bubble.
- **[Firecrawl Agent](https://github.com/NikhilPatil15/Firecrawl-agent)**: an agent that visits an online store it has never seen, figures out how the store works and places an order.
- **[MeetAI](https://github.com/NikhilPatil15/meet-ai)**: video meetings with live transcripts and a summary at the end. [Try it](https://meet-ai.vercel.app).
- **[EduQuest](https://github.com/NikhilPatil15/EduQuest)**: learning, turned into a Pokémon-style game.
- **[VideoHub](https://github.com/NikhilPatil15/VideoHub-Backend)**: the backend for a video platform, with auth, uploads and streaming.

#### What I usually reach for

TypeScript, Next.js and Node, with Python when it fits. Postgres (often through Supabase), MongoDB and Redis for data. Claude, GPT or Gemini, depending on the job.
